The [blog](/blog/) is where an idea gets introduced. This is where it gets argued.

Each article here takes one claim from the Protocol-Governed Computing Standard and pushes on it
until it either holds or breaks. Where it broke, that is written down too — including the places
where the standard turned out to be wrong and the implementation turned out to be right.

The draft standard is open and unfinished, which is the point. The strongest test of a specification
is whether someone who did not build the reference implementation can implement it anyway.
